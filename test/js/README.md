# Test fixtures

- `require.min.js`: [RequireJS](https://requirejs.org/) 2.3.7 (MIT License,
  Copyright jQuery Foundation and other contributors), used by
  `amdjs_native_test.dart` to test the native AMD implementation.
- `amd-*.js`, `pkg-*/`: AMD modules (`define(...)`) loaded natively.
- `plain-*.js`, `mimic/`: plain scripts (setting globals) loaded by the
  Dart mimic implementation.
